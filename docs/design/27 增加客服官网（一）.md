## 功能概述

### 1.1 功能列表

这篇文章将实现以下功能：

-   ✅ **官网首页**：导航、首屏 Hero、功能矩阵、工作台展示、实时演示、行业方案、客户案例、数据横幅、定价、FAQ、底部 CTA、页脚订阅

-   ✅ **真实套餐价格**：官网展示的价格 = 控制台下单的价格（同一份 `plan` 表数据，不会对不上）

-   ✅ **文案后台可下发**：平台「官网配置」发布后，官网标题、统计、FAQ、页脚等立即跟着变

-   ✅ **产品实时演示**：机器人接待 → 知识库引用 → 转人工 → 满意度评价，点开就能玩

-   ✅ **SEO 友好**：内容写在 HTML 里（价格、FAQ 都有静态兜底），另有结构化数据与 canonical

-   ✅ **零依赖**：HTML + CSS + 原生 JavaScript，没有 npm 依赖、没有构建工具，改文案不用重新打包

-   ✅ **接口挂了不白屏**：后端没起时价格自动落到静态兜底，官网照常打开

-   ✅ **一键预览与部署**：IDEA 里点一下就能跑（端口被占用会自动重启），生产直接丢 nginx / Docker

### 1.2 技术栈

**后端技术**

-   Spring Boot 3.x（在现有网关 + 微服务里加两个公开接口）

-   MyBatis-Plus 3.x（套餐数据来自 billing 服务的 `plan` 表）

-   网关路由：官网的 `/api/**` 由网关转发到各微服务

**官网技术**

-   原生 HTML5 + CSS3 + ES5/ES6 JavaScript（零依赖）

-   Python 3 标准库（本地预览服务器 `serve.py`、自检脚本 `verify-official.py`）

-   Node.js 内置模块（等价的预览服务器 `serve.mjs`、构建脚本 `build.mjs`）

-   nginx / Docker（生产部署）

### 1.3 项目结构

官网是一个**独立项目**（和后台管理系统分开部署，缓存策略、域名、发布节奏都不一样）：

``` code-block-container
customer-service/
├── yunti-backend/                        # 后端（现有）
│   ├── yunti-billing-service/            # 计费服务 → 加「公开套餐」接口
│   └── yunti-ops-service/                # 运营服务 → 加「官网配置」接口 + site-config.json
├── yunti-frontend/                       # 管理后台（现有，本教程不改）

    ├── legal.html                        # 服务协议与隐私政策

    ├── assets/css/site.css               # 样式
    ├── assets/js/site.js                 # 交互 + 真实数据接入
    ├── scripts/serve.py                  # 预览服务器（Python 标准库）
    ├── scripts/serve.mjs                 # 预览服务器（Node 内置模块，等价实现）
    ├── scripts/build.mjs                 # 构建到 dist/

```

### 1.4 数据是怎么流到官网的

``` code-block-container
访客浏览器
   │  打开官网（静态 HTML/CSS/JS）
   ▼
yunti-official ──fetch──▶  /api/billing/public/plans   （网关 → billing 9094 → plan 表）
   │                                   └─ 拿到真实套餐 → 重画定价卡片
   └───────────fetch──▶  /api/ops/public/site-config  （网关 → ops 9095 → site-config.json）
                                       └─ 拿到文案 → 覆盖页面默认文案
接口拿不到时：价格用页面里的静态兜底、文案用默认文案，官网照常打开（不会白屏）
```

### 2.3 先搞清三个概念

|                         |                                                                                                                                  |
|-------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| 概念                    | 说明                                                                                                                             |
| 套餐（plan 表）         | 定价数据只有一份：后台下单用它，官网展示也用它，所以价格永远对得上                                                               |
| 官网配置（site-config） | 官网的文案（标题 / 统计 / FAQ / 页脚等）放后端，页面上用 `data-cfg="hero.title1"` 这样的标记指出「这块文案对应配置里的哪个字段」 |
| 静态兜底                | 页面 HTML 里本来就写了一份价格与文案：接口通了用真实数据覆盖，接口挂了就用兜底，保证官网不会白屏、爬虫也能抓到内容               |

## 后端开发：两个公开接口

### 3.1 接口设计要点

官网是给**还没注册的访客**看的，所以这两个接口必须免登录；但要满足三条：

1.  **只读**：公开接口不能有任何写操作，避免被人拿来当入口；

2.  **不含敏感信息**：套餐只回名称、价格、配额这些本来就印在官网上的字段；

3.  **失败可降级**：官网拿不到数据也要能正常打开（这一点由前端兜底 + 后端异常兜底共同保证）。

分工：**定价**属于计费域，放 `yunti-billing-service`；**官网文案**属于平台运营，放 `yunti-ops-service`——不放业务服务里，避免越权拿租户数据。

### 3.2 步骤1：新增「公开套餐」接口

打开 `yunti-backend/yunti-billing-service/src/main/java/cn/net/susan/billing/controller/BillingController.java`，在类里加下面这个方法（完整代码）：

``` code-block-container
    /**
     * 官网定价用的**公开**套餐列表（不需要登录）。
     *
     * <p>官网是给还没注册的人看的，不能让它先登录。这里只回"上架且启用"的套餐，
     * 字段与内部接口一致——外部报价与后台开通用同一套数据，避免官网写死价格后对不上。</p>
     */
    @GetMapping("/public/plans")
    public ApiResponse<List<Map<String, Object>>> publicPlans() {
        List<Map<String, Object>> list = new java.util.ArrayList<>();
        for (Plan plan : billingService.plans()) {
            Map<String, Object> item = new java.util.LinkedHashMap<>();
            item.put("planCode", plan.getPlanCode());
            item.put("planName", plan.getPlanName());
            item.put("priceYearly", plan.getPriceYearly());
            item.put("priceMonthly", plan.getPriceMonthly());
            item.put("quotaRobotSessions", plan.getQuotaRobotSessions());
            item.put("quotaChannels", plan.getQuotaChannels());
            item.put("quotaSeats", plan.getQuotaSeats());
            item.put("quotaStorageGb", plan.getQuotaStorageGb());
            item.put("quotaAiCalls", plan.getQuotaAiCalls());
            item.put("quotaAiQa", plan.getQuotaAiQa());
            item.put("quotaVision", plan.getQuotaVision());
            item.put("overagePricePerK", plan.getOveragePricePerK());
            list.add(item);
        }
        return ApiResponse.ok(list);
    }
```

说明：

-   路径是 `/api/billing/public/plans`，`public` 前缀表示公开，网关照常转发，不需要动网关配置；

-   复用 `billingService.plans()`（后台「套餐」页用的是同一个方法），所以官网价格与后台一致；

-   只回官网需要的字段（名称 / 年价 / 月价 / 配额 / 超量单价），不外泄成本价之类的内部字段。

### 3.4 步骤3：新增「官网配置」接口

新建 `yunti-backend/yunti-ops-service/src/main/java/cn/net/susan/ops/controller/OpsPublicController.java`（完整内容）：

``` code-block-container
package cn.net.susan.ops.controller;

import cn.net.susan.common.api.ApiResponse;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.core.io.ClassPathResource;
import tools.jackson.core.type.TypeReference;
import tools.jackson.databind.ObjectMapper;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.Map;

// 官网公开接口：把「官网配置」下发给官网项目。
//
// 官网（yunti-official）是独立部署的静态站点，打开时拉这份配置来覆盖默认文案
// （hero 标题、统计数字、定价说明、FAQ、页脚版权…）。当前配置来自
// resources/site-config.json（版本化、可 diff、可评审）；等平台侧「官网配置」页做好，
// 把数据源换成 DB 即可，官网侧一行都不用改。
//
// 为什么放 ops：官网配置属于平台运营范畴（与租户数据无关），不该混在业务服务里。
@RestController
@RequestMapping("/api/ops/public")
public class OpsPublicController {

    private static final Logger log = LoggerFactory.getLogger(OpsPublicController.class);
    private static final ObjectMapper MAPPER = new ObjectMapper();

    /** 官网配置（原样返回 JSON 对象，官网按字段覆盖默认文案） */
    @GetMapping("/site-config")
    public ApiResponse<Map<String, Object>> siteConfig() {
        try (InputStream in = new ClassPathResource("site-config.json").getInputStream()) {
            String json = new String(in.readAllBytes(), StandardCharsets.UTF_8);
            return ApiResponse.ok(MAPPER.readValue(json, new TypeReference<Map<String, Object>>() {
            }));
        } catch (Exception e) {
            // 配置读不到不能让官网白屏：返回空对象，官网会用静态默认文案
            log.warn("读取 site-config.json 失败：{}", e.getMessage());
            return ApiResponse.ok(Map.of());
        }
    }
}
```

两个细节：

-   读不到配置文件时返回**空对象**而不是报错：官网收到空对象会继续用默认文案，不会因为配置服务异常而白屏；

-   该服务用的是 Jackson 3（`tools.jackson.*`），不是 Jackson 2——照抄别的服务的 import 会编译不过。

### 3.5 步骤4：编译并自测接口

期望：两个接口\*\*不带 Authorization 也能返回 \*\*`code: 0`。如果返回 401，说明路径被当成需要登录的接口了，检查类上的 `@RequestMapping` 前缀是否正确。

### 4.2 步骤6：写本地预览服务器

本地直接双击 `index.html` 也能看，但那样取不到后端数据（浏览器不允许 `file://` 发 API 请求）。所以我们写一个**只用 Python 标准库**的预览服务器：静态托管 + 把 `/api` 反代到网关。

新建 `yunti-official/scripts/serve.py`（完整内容）：

``` code-block-container
#!/usr/bin/env python3
"""云梯智能客服 · 官网本地预览服务器（纯标准库，IDEA 里可直接运行、可反复执行）。

用法（命令行）：
    python3 scripts/serve.py                  # http://localhost:5180，端口被上一次占用会自动重启
    python3 scripts/serve.py --port 5181
    python3 scripts/serve.py --no-open        # 不自动打开浏览器
    python3 scripts/serve.py --no-restart     # 端口被占用时直接报错，不碰任何进程
    python3 scripts/serve.py --force          # 端口被"别的程序"占用时也强行清掉再起
    python3 scripts/serve.py --api-base http://127.0.0.1:9090/api

用法（IntelliJ IDEA）：右键本文件 → Run 'serve'；或运行下拉里选「官网预览」。

它干三件事：
  1. **可重复执行**：启动前先看端口。占用者是"上一次的官网预览服务"就自动停掉再重启，
     不用手动 kill，也不会因为 Address already in use 启动失败；
  2. 把 yunti-official/ 当静态站托管（和生产 nginx 一致：找不到的路径回落到 index.html）；
  3. 把 /api/** 反代到后端网关（默认 http://127.0.0.1:9090/api），
     这样本地就能拿到后台"真实套餐价格"与"官网配置"——
     网关没起也不影响官网打开，价格会自动落到静态兜底。

为什么不用 vite/webpack：官网是纯静态站点（HTML + CSS + 原生 JS，SEO 友好、可整站丢 CDN），
引构建工具只会带来依赖与版本负担；这里只用 Python 标准库，不装任何包，IDEA 里点一下就能跑。
"""

    ".mjs": "text/javascript; charset=utf-8",

# =====================================================================
# 端口占用处理：认出"上一次的预览服务"，停掉它，再重新启动
# =====================================================================

def _run(command: list[str]) -> str:
    try:
        completed = subprocess.run(command, capture_output=True, text=True, timeout=5)
        return (completed.stdout or "").strip()
    except Exception:  # noqa: BLE001 - 环境里没有这个命令就算了
        return ""


def process_table() -> list[tuple[int, str]]:
    """当前进程表：[(pid, 完整命令行)]，用于识别"是不是我们自己起的预览服务"。"""
    rows: list[tuple[int, str]] = []
    for line in _run(["ps", "-ax", "-o", "pid=,command="]).splitlines():
        line = line.strip()
        if not line:
            continue
        pid_text, _, command = line.partition(" ")
        if pid_text.isdigit():
            rows.append((int(pid_text), command.strip()))
    return rows


def cmdline_of(pid: int) -> str:
    for row_pid, command in process_table():
        if row_pid == pid:
            return command
    return ""


def looks_like_preview(command: str) -> bool:
    """是不是"本项目的官网预览服务"：serve.sh / scripts/serve.py / scripts/serve.mjs。"""
    if not command:
        return False
    if "yunti-official" not in command and str(ROOT) not in command:
        return False
    return any(token in command for token in ("serve.sh", "scripts/serve.py", "scripts/serve.mjs"))


def listening_pids(port: int) -> list[int]:
    """谁在监听这个端口：macOS 用 lsof，Linux 用 ss / fuser。"""
    pids: set[int] = set()
    if shutil.which("lsof"):
        for token in _run(["lsof", "-nP", f"-iTCP:{port}", "-sTCP:LISTEN", "-t"]).split():
            if token.isdigit():
                pids.add(int(token))
    if not pids and shutil.which("ss"):
        for match in re.findall(r"pid=(\d+)", _run(["ss", "-ltnp", f"sport = :{port}"])):
            pids.add(int(match))
    if not pids and shutil.which("fuser"):
        for token in _run(["fuser", "-n", "tcp", str(port)]).split():
            if token.isdigit():
                pids.add(int(token))
    pid_file = read_pid_file()
    if pid_file and pid_file not in pids and cmdline_of(pid_file) and looks_like_preview(cmdline_of(pid_file)):
        pids.add(pid_file)
    return sorted(pids)


def read_pid_file() -> int | None:
    try:
        return int(PID_FILE.read_text(encoding="utf-8").strip())
    except Exception:  # noqa: BLE001 - 文件不在 / 内容坏了都当没有
        return None


def write_pid_file(pid: int) -> None:
    try:
        PID_FILE.write_text(str(pid), encoding="utf-8")
    except OSError:
        pass


def clear_pid_file(pid: int) -> None:
    if read_pid_file() == pid:
        try:
            PID_FILE.unlink()
        except OSError:
            pass


def port_is_free(port: int, host: str = "127.0.0.1") -> bool:
    probe = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    probe.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    try:
        probe.bind((host, port))
        return True
    except OSError:
        return False
    finally:
        probe.close()


def wait_port_free(port: int, timeout: float = 6.0) -> bool:
    deadline = time.time() + timeout
    while time.time() < deadline:
        if port_is_free(port):
            return True
        time.sleep(0.25)
    return port_is_free(port)


def stop_process(pid: int, timeout: float = 5.0) -> bool:
    """先 SIGTERM，给它时间自己收尾；还不退就 SIGKILL。"""
    if pid == os.getpid():
        return False
    try:
        os.kill(pid, signal.SIGTERM)
    except ProcessLookupError:
        return True
    except PermissionError:
        return False
    deadline = time.time() + timeout
    while time.time() < deadline:
        if not _alive(pid):
            return True
        time.sleep(0.2)
    try:
        os.kill(pid, signal.SIGKILL)
    except OSError:
        return not _alive(pid)
    for _ in range(10):
        if not _alive(pid):
            return True
        time.sleep(0.2)
    return not _alive(pid)


def _alive(pid: int) -> bool:
    try:
        os.kill(pid, 0)
        return True
    except OSError:
        return False


def stop_previous(port: int, force: bool = False) -> tuple[bool, list[str]]:
    """停掉上一次占着这个端口的预览服务。返回 (是否已腾出端口, 过程说明)。"""
    notes: list[str] = []
    pids = listening_pids(port)
    if not pids:
        # 端口占用但查不到监听进程（IPv6、权限受限等）：退化成"找我们自己的预览进程"
        pids = [pid for pid, command in process_table()
                if pid != os.getpid() and looks_like_preview(command)]
    if not pids:
        notes.append("没查到占用端口的进程（可能是别的用户/容器占的），直接尝试重新绑定。")
        return port_is_free(port), notes

    ours, others = [], []
    for pid in pids:
        if pid == os.getpid():
            continue
        command = cmdline_of(pid)
        (ours if looks_like_preview(command) else others).append((pid, command))

    if others and not force:
        detail = "、".join(f"PID {pid}（{(cmd or '未知进程')[:60]}）" for pid, cmd in others)
        notes.append(f"端口 {port} 被别的程序占用：{detail}")
        notes.append("这不是官网预览服务，我没有动它。可以：①换个端口 --port 5181；"
                     "②确认可以停掉它时加 --force。")
        return False, notes

    targets = ours + (others if force else [])
    for pid, command in targets:
        label = "上一次的官网预览服务" if looks_like_preview(command) else "占用端口的其他程序"
        notes.append(f"停止{label}：PID {pid}")
        if not stop_process(pid):
            notes.append(f"⚠️ PID {pid} 没停下来（可能是别的用户起的，权限不够）")

    freed = wait_port_free(port)
    notes.append(f"端口 {port} {'已释放' if freed else '仍被占用'}")
    return freed, notes


# =====================================================================
# HTTP：静态文件 + /api 反代（与 scripts/serve.mjs 行为一致）
# =====================================================================

class Handler(BaseHTTPRequestHandler):

    server_version = "YuntiOfficialPreview/1.0"
    protocol_version = "HTTP/1.1"

    def __init__(self, *args, api_base: str, quiet: bool = False, **kwargs):
        self.api_base = api_base.rstrip("/")
        self.quiet = quiet
        super().__init__(*args, **kwargs)

    def do_GET(self):
        self.dispatch()

    def do_HEAD(self):
        self.dispatch()

    def do_POST(self):
        self.dispatch()

    def do_PUT(self):
        self.dispatch()

    def do_DELETE(self):
        self.dispatch()

    def do_PATCH(self):
        self.dispatch()

    def dispatch(self):
        path = self.path.split("?", 1)[0]
        try:
            if path == "/api" or path.startswith("/api/"):
                self.proxy()
            else:
                self.static()
        except (BrokenPipeError, ConnectionResetError):
            # 浏览器提前断开（刷新、切页）不是错误，没必要打堆栈
            pass
        except Exception as error:  # noqa: BLE001 - 预览服务器，兜住就行
            self.send_json(500, {"code": 50000, "message": f"预览服务出错：{error}", "data": None})

    # ------------------------------------------------------------ 静态文件
    def static(self):
        raw = unquote(self.path.split("?", 1)[0])
        target = (ROOT / raw.lstrip("/")).resolve()
        # 目录穿越保护：只允许访问官网项目目录内的文件
        if ROOT not in target.parents and target != ROOT:
            self.send_json(403, {"code": 40300, "message": "禁止访问项目目录以外的文件", "data": None})
            return
        if target.is_dir():
            target = target / "index.html"
        if not target.is_file():
            # 与 nginx 的 try_files 一致：找不到就回落到首页
            target = ROOT / "index.html"
        body = target.read_bytes()
        self.log_line(f"静态  {self.path}  →  200 {target.name}（{len(body) / 1024:.1f} KB）")
        self.send_response(200)
        self.send_header("Content-Type", HTML_TYPES.get(target.suffix.lower(), "application/octet-stream"))
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", "no-store")
        self.end_headers()
        if self.command != "HEAD":
            self.wfile.write(body)

    # ------------------------------------------------------------ /api 反代
    def proxy(self):
        upstream = self.api_base + self.path[len("/api"):]
        length = int(self.headers.get("Content-Length") or 0)
        payload = self.rfile.read(length) if length else None
        headers = {
            key: value
            for key, value in self.headers.items()
            if key.lower() not in {"host", "connection", "content-length", "accept-encoding"}
        }
        request = urllib.request.Request(upstream, data=payload, headers=headers, method=self.command)
        try:
            with urllib.request.urlopen(request, timeout=15) as response:
                body = response.read()
                status = response.status
                content_type = response.headers.get("Content-Type", "application/json; charset=utf-8")
        except urllib.error.HTTPError as error:
            body = error.read()
            status = error.code
            content_type = error.headers.get("Content-Type", "application/json; charset=utf-8")
        except Exception as error:  # noqa: BLE001 - 网关没起时给官网一个明确的 502
            self.log_line(f"代理  {self.path}  →  502（网关不可用：{error}）")
            self.send_json(502, {
                "code": 50200,
                "message": f"后端网关不可用（{self.api_base}），官网会用静态兜底价：{error}",
                "data": None,
            })
            return
        self.log_line(f"代理  {self.path}  →  {status} ← {upstream}")
        self.send_response(status)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        if self.command != "HEAD":
            self.wfile.write(body)

    # ------------------------------------------------------------ 小工具
    def send_json(self, status: int, payload: dict):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        if self.command != "HEAD":
            self.wfile.write(body)

    def log_line(self, text: str):
        if not self.quiet:
            print("  " + text, flush=True)

    def log_message(self, fmt: str, *args):  # 关掉默认的逐行日志，用上面的中文日志代替
        return

# 启动
# =====================================================================

def bind_server(host: str, port: int, api_base: str, quiet: bool) -> ThreadingHTTPServer:
    handler = partial(Handler, api_base=api_base, quiet=quiet)
    return ThreadingHTTPServer((host, port), handler)


def main() -> int:
    parser = argparse.ArgumentParser(description="云梯智能客服 · 官网本地预览")
    parser.add_argument("-p", "--port", type=int,
                        default=int(os.environ.get("PORT") or os.environ.get("YUNTI_OFFICIAL_PORT") or 5180),
                        help="监听端口（默认 5180，也可用环境变量 PORT）")
    parser.add_argument("--host", default="127.0.0.1", help="监听地址（默认 127.0.0.1）")
    parser.add_argument("--api-base",
                        default=os.environ.get("YUNTI_API_BASE") or "http://127.0.0.1:9090/api",
                        help="后端网关地址（默认 http://127.0.0.1:9090/api，也可用环境变量 YUNTI_API_BASE）")
    parser.add_argument("--no-open", action="store_true", help="不自动打开浏览器")
    parser.add_argument("--quiet", action="store_true", help="不打印每个请求")
    parser.add_argument("--no-restart", action="store_true",
                        help="端口被占用时直接报错退出，不自动停掉上一次的预览服务")
    parser.add_argument("--force", action="store_true",
                        help="端口被别的程序占用时也强行停掉（默认只重启官网自己的预览服务）")
    args = parser.parse_args()

    if not (ROOT / "index.html").is_file():
        print(f"❌ 没找到官网首页：{ROOT / 'index.html'}", file=sys.stderr)
        return 1

    def start():
        return bind_server(args.host, args.port, args.api_base, args.quiet)

    # ── 1) 可重复执行：端口被上一次的预览服务占着就先停掉它
    restarted = False
    try:
        httpd = start()
    except OSError as error:
        busy = error.errno in (errno.EADDRINUSE, 48, 98)
        if busy and not args.no_restart:
            print(f"⟳ 端口 {args.port} 已被占用，先停掉上一次的预览服务再重启…")
            freed, notes = stop_previous(args.port, force=args.force)
            for note in notes:
                print("   " + note)
            if not freed:
                print(f"❌ 端口 {args.port} 还是被占用，换个端口试试："
                      f"python3 scripts/serve.py --port {args.port + 1}", file=sys.stderr)
                return 1
            try:
                httpd = start()
                restarted = True
            except OSError as retry_error:
                print(f"❌ 重启后仍起不来：{retry_error}", file=sys.stderr)
                return 1
        else:
            if busy:
                print(f"❌ 端口 {args.port} 被占用（已按 --no-restart 要求不做处理）", file=sys.stderr)
            elif error.errno in (errno.EPERM, errno.EACCES):
                print(f"❌ 没有权限监听 {args.host}:{args.port}：{error}", file=sys.stderr)
            else:
                print(f"❌ 端口 {args.port} 起不来：{error}", file=sys.stderr)
            print(f"   换个端口试试：python3 scripts/serve.py --port {args.port + 1}", file=sys.stderr)
            return 1

    write_pid_file(os.getpid())

    url = f"http://{'localhost' if args.host in ('127.0.0.1', '0.0.0.0') else args.host}:{args.port}/"
    print()
    print("云梯智能客服 · 官网本地预览" + ("（已自动重启）" if restarted else ""))
    print(f"  访问地址：{url}")
    print(f"  站点目录：{ROOT}")
    print(f"  API 反代：/api  →  {args.api_base}")
    print(f"  进程号：{os.getpid()}（下次再跑本脚本会自动顶替它，不需要手动 kill）")
    print("  提示：「登录 / 免费试用」默认跳管理端 http://localhost:5173，")
    print(f"       想换地址就打开 {url}?app=http://localhost:5173")
    print("  停止：在控制台按 Ctrl + C（IDEA 里点红色 ■）")
    print()

    if not args.no_open:
        threading.Timer(0.6, lambda: webbrowser.open(url)).start()

    # 被下一次启动 SIGTERM 掉的时候也走同一套收尾逻辑（不留僵尸、不留 pid 文件）
    def on_signal(signum, frame):  # noqa: ARG001
        raise KeyboardInterrupt

    signal.signal(signal.SIGTERM, on_signal)
    signal.signal(signal.SIGINT, on_signal)

    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        print("\n已停止官网预览服务。")
    finally:
        httpd.server_close()
        clear_pid_file(os.getpid())
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

这个脚本顺手解决了一个每天都会遇到的小麻烦：**端口被上一次的进程占着**。它会先看端口占用者是不是「自己上一次启动的预览服务」，是就自动停掉再重启（可重复执行），是别的程序则不动它，只提示你换端口或加 `--force`。

### 4.4 步骤8：写构建脚本

新建 `yunti-official/scripts/build.mjs`（完整内容）：

``` code-block-container
/**
 * 官网构建（零依赖）：把站点复制到 dist/，并按环境变量注入 API 前缀。
 *
 *   node scripts/build.mjs
 *   YUNTI_API_BASE=https://api.yunti.example.com/api node scripts/build.mjs
 *
 * 产物 dist/ 是纯静态文件，直接丢 CDN / nginx 即可（见 Dockerfile 与 README）。
 */
import fs from 'node:fs'
import path from 'node:path'
import { fileURLToPath } from 'node:url'

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..')
const DIST = path.join(ROOT, 'dist')
const API_BASE = process.env.YUNTI_API_BASE || '/api'
const APP_BASE = process.env.YUNTI_APP_BASE || ''

fs.rmSync(DIST, { recursive: true, force: true })
fs.mkdirSync(DIST, { recursive: true })

function copyDir(from, to) {
  for (const entry of fs.readdirSync(from, { withFileTypes: true })) {
    if (entry.name === 'dist' || entry.name === 'scripts') continue
    const src = path.join(from, entry.name)
    const dest = path.join(to, entry.name)
    if (entry.isDirectory()) {
      fs.mkdirSync(dest, { recursive: true })
      copyDir(src, dest)
    } else {
      fs.copyFileSync(src, dest)
    }
  }
}

copyDir(ROOT, DIST)

// 注入 API 前缀与管理端地址：改一处，全站生效
const indexFile = path.join(DIST, 'index.html')
let html = fs.readFileSync(indexFile, 'utf8')
html = html.replace(
  /<meta name="yunti-api-base" content="[^"]*" \/>/,
  `<meta name="yunti-api-base" content="${API_BASE}" />`,
)
if (APP_BASE) {
  html = html.replace(
    '<script src="assets/js/site.js" defer></script>',
    `<script>window.YUNTI_APP_BASE = ${JSON.stringify(APP_BASE)};</script>\n<script src="assets/js/site.js" defer></script>`,
  )
}
fs.writeFileSync(indexFile, html, 'utf8')

const files = fs.readdirSync(DIST, { recursive: true }).length
console.log(`构建完成：${DIST}`)
console.log(`  API 前缀：${API_BASE}${APP_BASE ? ` · 管理端：${APP_BASE}` : ''}`)
console.log(`  文件数：${files}`)
```

构建做的事很少，但很关键：把站点拷到 `dist/`，并把 **API 前缀**和**管理端地址**注入进去。这样同一份源码可以部署到测试、生产两套环境，不用改代码。
